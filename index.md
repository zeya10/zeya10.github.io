## 🌟 About svelte-bash
svelte-bash is a fully typed, lightweight, and customizable terminal emulator component designed specifically for Svelte 5. This software provides an engaging command-line experience with a virtual file system, custom commands, themes, and an autoplay mode for easy demos. Perfect for anyone wanting a simple way to use terminal features within their web applications.

## 🚀 Features
- **Lightweight Design:** Uses minimal resources while delivering maximum performance.
- **Custom Commands:** Easily configure commands to fit your needs.
- **Themes:** Choose from various styles to personalize your terminal experience.
- **Virtual File System:** Simulate a file structure for a more realistic interaction.
- **Autoplay Mode:** Automatically run commands for demonstration purposes.
